<details>
<summary><b>💡 How I like to build</b></summary>
<br>

- **Automate the repetitive**: make room for engineering work that solves new problems.
- **Platforms over snowflakes**: build reusable paths teams can operate consistently.
- **Security by default**: make the safer choice the easiest choice.
- **Prefer declarative systems**: keep desired state visible, reviewable, and repeatable.
- **Make complexity disappear for developers**: keep platform internals out of the way.
- **Operate what you build**: design for the people who will run it.

</details>
